# محمّل الفيديوهات (برنامج كمبيوتر)

الصق أي رابط (يوتيوب، تيك توك، إنستغرام، فيسبوك، تويتر ... +1000 موقع) واختر الجودة، والفيديو يُحفظ على جهازك.
يشتغل محلياً بالكامل: خادم صغير على 127.0.0.1 + واجهة تفتح كنافذة تطبيق (Edge/Chrome).

## التشغيل
1. ثبّت Python 3.10+ من python.org (فعّل Add to PATH).
2. دبل كليك على `run.bat`.

## ملف exe واحد
دبل كليك على `build_exe.bat` ← `dist\VideoDownloader.exe`.

## المميزات
- يسألك: فيديو أم صوت؟ ثم يعرض فقط الجودات المتاحة فعلاً في المقطع (مع الحجم)، وللصوت: أصلي بدون تحويل أو MP3 بجودة 320/192/128.
- بعد التحميل تظهر أزرار: فتح الملف، فتح المجلد، حذف.
- عدة روابط دفعة واحدة، وقوائم التشغيل الكاملة.
- طابور تحميل بشريط تقدم وسرعة ووقت متبقٍ، مع إلغاء وإعادة محاولة وسجل محفوظ.
- ترجمة SRT، حد للسرعة، عدد تحميلات متزامنة، كوكيز من المتصفح للمحتوى الخاص.
- يدمج الصوت والفيديو تلقائياً (ffmpeg مضمّن عبر imageio-ffmpeg).
- أمان: يستمع على 127.0.0.1 فقط، وكل الطلبات تحتاج توكن عشوائي لكل تشغيل.

## ملاحظات
- يقفل البرنامج نفسه بعد إغلاق النافذة (إذا لا يوجد تحميل شغّال).
- إعدادات وسجل التحميل في `~/.video-downloader`.
- لو موقع وقف: من الإعدادات اضغط «تحديث yt-dlp» (أو `pip install -U yt-dlp`).
- حمّل فقط ما يحق لك تحميله.
