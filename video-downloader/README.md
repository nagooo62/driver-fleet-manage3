# محمّل الفيديوهات (برنامج كمبيوتر)

الصق أي رابط (يوتيوب، تيك توك، إنستغرام، فيسبوك، تويتر ...) واختار الجودة وحمّل الفيديو على جهازك.
يعتمد على yt-dlp ويدمج الصوت والفيديو تلقائياً (ffmpeg يجي مع المكتبات).

## التشغيل
1. ثبّت Python 3.10+ من python.org (فعّل خيار Add to PATH).
2. دبل كليك على `run.bat`.

## عمل ملف exe
دبل كليك على `build_exe.bat`، يطلع `dist\VideoDownloader.exe` تقدر تنقله لأي مكان.

## ملاحظات
- لو الموقع طلب تسجيل دخول، اختر المتصفح في خانة «كوكيز».
- لو توقف موقع عن التحميل: `pip install -U yt-dlp`.
- حمّل فقط ما يحق لك تحميله.
