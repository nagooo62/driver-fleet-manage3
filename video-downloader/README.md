# محمّل الفيديوهات (برنامج كمبيوتر)

الصق أي رابط (يوتيوب، تيك توك، إنستغرام، فيسبوك، تويتر ... +1000 موقع) واختر الجودة، والفيديو يُحفظ على جهازك.
يشتغل محلياً بالكامل: خادم صغير على 127.0.0.1 + واجهة تفتح كنافذة تطبيق (Edge/Chrome).

## التشغيل
1. ثبّت Python 3.10+ من python.org (فعّل Add to PATH).
2. دبل كليك على `run.bat`.

## ملف exe واحد
دبل كليك على `build_exe.bat` ← `dist\VideoDownloader.exe`.

## المميزات
- يسألك: فيديو أم صوت؟ ثم يعرض فقط الجودات المتاحة فعلاً في المقطع (مع الحجم)، وللصوت: أصلي بدون تحويل أو MP3 بجودة 320/192/128.
- بعد التحميل تظهر أزرار: فتح الملف، فتح المجلد، حذف.
- عدة روابط دفعة واحدة، وقوائم التشغيل الكاملة.
- طابور تحميل بشريط تقدم وسرعة ووقت متبقٍ، مع إلغاء وإعادة محاولة وسجل محفوظ.
- ترجمة SRT، حد للسرعة، عدد تحميلات متزامنة، كوكيز من المتصفح للمحتوى الخاص.
- يدمج الصوت والفيديو تلقائياً (ffmpeg مضمّن عبر imageio-ffmpeg).
- أمان: يستمع على 127.0.0.1 فقط، وكل الطلبات تحتاج توكن عشوائي لكل تشغيل.

## ميزات إضافية
- 🔍 بحث داخل يوتيوب وساوند كلاود بدون فتح المتصفح، ثم اختيار الجودة.
- اكتشاف الرابط من الحافظة (يظهر شريط «رابط جديد» عند الرجوع للنافذة)، وسحب وإفلات الروابط، واستيراد روابط من ملف نصي.
- ✂ قص جزء من المقطع (من ثانية كذا إلى ثانية كذا) بدون تحميله كاملاً.
- صيغ صوت إضافية: M4A وFLAC وWAV، وصيغة الفيديو MP4 أو MKV أو WebM.
- 🎞 مشغّل داخل البرنامج للملفات المحمّلة، وإشعار وصوت عند الانتهاء، وبحث وإحصائيات في سجل التحميلات.
- فرز تلقائي (Video / Audio)، وبروكسي اختياري.

## 💿 تثبيت كتطبيق (Setup.exe)
- يُبنى تلقائياً على GitHub: افتح تبويب **Actions** ← آخر تشغيل لـ «Build Video Downloader (Windows)» ← **Artifacts** ← نزّل `VideoDownloader-Setup` (ملف zip فيه Setup.exe).
- أو ابنه على جهازك بتشغيل `build_windows.bat` (يحتاج Python، وInno Setup لإنشاء Setup.exe).
- النسخة المثبّتة: بلا نافذة سوداء ولا Python، وأيقونة بجوار الساعة (فتح / مجلد التحميلات / التشغيل مع ويندوز / خروج)، وإشعار عند اكتمال التحميل، وتحديث yt-dlp من الإعدادات.
- مجلد إضافة المتصفح موجود داخلها: الإعدادات ← «مجلد إضافة المتصفح» ← فتح.
- قد يعرض ويندوز تحذير SmartScreen لأن الملف غير موقّع رقمياً: اضغط «More info» ثم «Run anyway».
- يوتيوب بجودات كاملة يحتاج Deno: الإعدادات ← «تثبيت دعم يوتيوب (Deno)».

## 🧩 إضافة المتصفح (Chrome / Edge)
زر تحميل يظهر على جانب صفحة الفيديو، وعند الضغط عليه تظهر الجودات ويُرسل التحميل لهذا البرنامج.
1. شغّل البرنامج، ثم افتح `chrome://extensions` (أو `edge://extensions`) وفعّل **وضع المطوّر**.
2. اضغط **Load unpacked / تحميل إضافة غير مضغوطة** واختر مجلد `extension` داخل مجلد البرنامج.
3. ستفتح صفحة الخيارات: الصق «رمز ربط إضافة المتصفح» من البرنامج (⚙ الإعدادات) ثم **حفظ واختبار الاتصال**.
- الإضافة لا ترسل شيئاً إلا حين تضغط الزر، وتتصل بجهازك المحلي فقط (127.0.0.1).
- يمكنك أيضاً الزر الأيمن على صفحة أو رابط ← «تحميل بأعلى جودة».

## ملاحظات
- يقفل البرنامج نفسه بعد إغلاق النافذة (إذا لا يوجد تحميل شغّال).
- إعدادات وسجل التحميل في `~/.video-downloader`.
- لو موقع وقف: من الإعدادات اضغط «تحديث yt-dlp» (أو `pip install -U yt-dlp`).
- حمّل فقط ما يحق لك تحميله.
